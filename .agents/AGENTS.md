# Project Rules

- **Git Push Reminder**: Al finalizar la sesión o concluir una tarea importante, recuerda siempre al usuario hacer commit y push del repositorio actualizado a Git (`git status`, `git add`, `git commit`, `git push`).
- **Autosave Git (Cada 1 hora)**: Cada 1 hora durante la sesión, ejecuta automáticamente `git add .`, un `git commit` descriptivo y `git push` para respaldar el avance del proyecto y evitar pérdidas de trabajo.
